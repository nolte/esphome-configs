# Christmas Tree

A classic seasonal use case: switch a Christmas tree's lights on and off on a fixed daily
schedule with a smart plug. The [Timed](../packages/timed.md) package covers this directly. It
turns `${id}_button_switch` on at a configured start time and off at an end time every day, and
both times stay editable from Home Assistant.

Pair it with a plug hardware package such as [Gosund SP111](../devices/switch/gosund-sp111.md)
or [NOUS A1T](../devices/switch/nous-a1t.md).
